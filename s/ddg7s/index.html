1

픽스필드가 자사 복제 코드를 통째로 공개함

픽스필드라는 AI 이미지·영상 생성 서비스가 자기 웹사이트를 그대로 따라 만들 수 있는 모든 코드를 깃허브에 올렸음. 누구나 이 코드를 가져다 그대로 복제된 웹사이트를 만들 수 있음.

근거"필드에서 본인들의 웹사이트를 그대로 똑같이 카피할 수 있는 모든 코드를 오픈소스로 공개했다"고 설명함
2

코드로 프로덕트 만들면 약 7,250만원 지원함

단순히 코드만 공개한 게 아니라, 이 오픈소스로 실제 프로덕트를 만들어 운영하면 픽스필드가 약 7,250만원를 지원해줌. 원화로 따지면 약 8천만원에서 9천만원 규모임.

근거"프로덕트를 만들게 되면 픽스필드에서 약 7,250만원을 지원한다"고 말함
3

API 신설하며 모델 가격을 낮춤

픽스필드가 이번에 API 기능을 새로 만들면서 여러 모델의 가격을 함께 낮춤. 시덴스 2.5 영상 기준 초당 가격이 약 247원에서 약 203원으로 내려감.

근거"이번에 API 기능을 새로 신설하면서 모든 가격을 낮춰줬다"고 설명함
4

API는 종량제라 구독보다 저렴할 수 있음

기존에는 월간·연간 구독료를 내야 했지만, API는 쓴 만큼만 돈을 내는 방식임. 사용량이 적은 사람은 구독보다 훨씬 저렴하게 이용할 수 있음.

근거"사용한만큼만 돈을 지불하는 종량제, 즉 API 사용을 하는 게 훨씬 더 저렴할 수도 있다"고 말함
5

대시보드에서 키 발급 후 결제 등록함

픽스필드 API 대시보드에서 키를 발급받고, 카드를 따로 등록해야 사용할 수 있음. 이때 결제 등록과 비즈니스 이메일 인증을 마치면 약 2만원의 무료 크레딧이 주어짐.

근거"페이먼트를 등록하고 비즈니스 이메일을 인증까지 하시면 무료로 사용할 수 있는 15불 크레딧이 주어진다"고 설명함
6

발급받은 키는 오픈소스 사이트에 등록함

발급받은 API 키를 직접 만든 오픈소스 웹사이트(또는 데모 사이트)에 붙여 넣고 저장하면 연동이 끝남. 이 키 정보는 브라우저에만 저장되고 외부로 유출되지 않음.

근거"키는 브라우저에 저장된다. 어디로 유출이 되는 게 아니다"라고 설명함
7

이미지 생성 비용이 장당 1센트 수준임

소울2라는 캐릭터 특화 이미지 모델로 직접 이미지를 만들어본 결과, 비용이 약 14원에 불과했음. 이미지만 자주 만드는 사람에게 매우 저렴한 선택지임.

근거"이미지 같은 경우는 지금 약 14원 들었다"고 확인함
8

시덴스 2.5 영상도 경쟁사보다 저렴함

15초짜리 픽셀 캐릭터 전쟁 장면 영상을 시덴스 2.5로 만들었을 때 비용은 약 8,540원였음. 같은 조건의 다른 플랫폼은 계산상 약 1만원이 나와 픽스필드가 더 저렴했음.

근거"타 플랫폼은 1초당 약 686원라 15초면 7불이 나오는데, 우리가 만든 건 5.89불이 나왔다"고 비교함
9

라이트 유저는 50에서 약 14만원 충전이면 충분함

이미지나 영상을 가끔 만드는 사람이라면 한 번에 약 7만원에서 약 14만원 정도만 충전해두면 크레딧이 부족할 일이 거의 없다고 설명함. 많이 쓰는 사람은 기존 구독 플랜이 더 나을 수 있음.

근거"한 50불에서 100불 정도만 넉넉하게 충전해 놓으시고 사용을 하시면 크레딧이 모자랄 일은 없을 것"이라고 말함
10

구독 플랜은 연간 결제 시 30% 할인됨

API 대신 픽스필드의 정식 플랜(플러스, 울트라)을 계속 이용하고 싶은 사람을 위한 구독 옵션도 남아 있음. 연간으로 가입하면 최대 30% 할인을 받을 수 있음.

근거"연간으로 가입하실 때 최대 30% 할인 혜택 받으실 수 있다"고 설명함

조심할 부분
  • 소개된 오픈소스 코드는 회사 공식 배포가 아니므로 보안 검증이나 유지보수 책임 소재가 불분명함
  • API는 종량제라 사용량 예측 실패 시 카드에 반복 과금될 수 있음
  • 결제 카드 등록 전 해당 서드파티 사이트의 개인정보·결제 정보 처리 방침을 따로 확인해야 함
  • 약 7,250만원는 코드와 무관한 별도 광고 대회 상금이므로 오해로 인한 참가 시간 낭비 가능성 있음
생각할 부분
  • 커뮤니티 클론 코드의 유지보수 중단 위험은 어떻게 판단할 것인가
  • 힉스필드가 실제로 API 마진을 줄인 이유(경쟁사 대응, 트래픽 확보 등)는 무엇인가
  • 동일 결과물을 다른 API 애그리게이터(fal.ai 등)에서 만들 때 총비용 비교가 선행되어야 함
  • "회사가 비밀 공개" 같은 표현이 실제로는 서드파티 프로젝트라는 점을 영상 시청 전에 확인하는 습관이 필요함
  • API 종량제 방식이 자신의 사용 패턴(라이트 유저 vs 헤비 유저)에 실제로 유리한지 스스로 계산해봐야 함
